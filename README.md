# Python Practice

A collection of Python scripts focusing on fundamental logic, mathematical algorithms, and basic game mechanics.

## 🚀 Projects Included

- **ATM Simulator**: A terminal-based simulation of bank transactions (Withdraw, Deposit, Balance check).
- **Tic Tac Toe Validator**: Logic to check if a 3x3 grid has a winner or is a draw.
- **Grade Calculator**: Processes numerical marks to determine letter grades based on specific logic.
- **Num Guess**: A fun interactive game where the computer thinks of a number and you try to guess it.
- **Mathematical Logic**: 
  - **Prime Num Checker**: Efficiently identifies if a number is prime.
  - **Fibonacci Generator**: Produces sequences based on the Fibonacci mathematical model.
  - **Factorial Calculator**: Computes the factorial of any given integer.
  - **Multiplication Table**: Generates tables for any number input.
- **Utility Checkers**:
  - **Palindrome Checker**: Verifies if a string reads the same backwards as forwards.
  - **Leap Year Checker**: Determines if a specific year is a leap year.
  - **Star Pattern**: Generates various geometric shapes using terminal characters.

## 📝 Learning Objectives
This repository serves as a personal record of mastering Python basics, including loops, conditional statements, and function logic.
